# WheelDecalsHub Optimization

Репозиторій містить оптимізаційні зміни для OpenCart/Plaza сайту WheelDecalsHub з акцентом на Core Web Vitals, PageSpeed, стабільний mobile render та безпечну роботу через OCMOD.

## Документація

Перед будь-якими змінами, що стосуються OCMOD, critical/deferred CSS, JavaScript, mobile layout, image delivery, fonts або cache, обов'язково прочитайте:

- [Архітектура оптимізації](docs/architecture/OPTIMIZATION_ARCHITECTURE.md)

Це головний технічний документ проєкту. Він описує поточний підхід до оптимізації, source of truth, порядок проходження змін через OCMOD і cache layers, правила безпечної роботи, типові помилки та danger zones.
